## Clipable Spacers
-------------------
A simple aid to rapid protoyping mechanisms in robotics competitions such as FRC.

Instead of having to constantly disassemble and reassemble mechanisms to test the distances between wheels, rollars, other parts on hex shafts, what if you could use a spacer which could on and off and allow you to easily test different placements.
Currently made for 0.5in shafts, clipable spacers allow for a easy and tight fit

Current features:
- Machined out of aluminum for strong durablility.
- Available in various different preset sizes
- Designed paramtrically and using equations for easy customibility
- Fast to manafacture
